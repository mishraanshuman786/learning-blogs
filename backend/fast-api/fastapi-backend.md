# FastApi Backend
Fastapi is a modern, fast(high-performance), web frameowork for building APIS with Python based on standard python hints.

`Uvicorn`: Uvicorn is an ASGI web server implementation for Python.

We can run directly from fastapi or use the Uvicorn to run the application.

`Pydantic`: Pydantic is the most widely use data validation library for Python. We can use this library for type cheking in fast api. Like Typescript in javascript , same Pydantic for python but more than that.

`typing module`: Core module for python. It is used for typehints in python.
